FONTLOG for NanGuo Pinyin
=========================

This file provides detailed information on the NanGuo Pinyin Font Software.
This information should be distributed along with the NanGuo Pinyin fonts
and any derivative works.

Basic Font Information
----------------------
NanGuo Pinyin is a Simplified Chinese educational typeface that embeds
Hanyu Pinyin pronunciation guides directly above each Chinese character
as font-native composite glyphs.

The font is built on Noto Sans SC as a base and adds 1,349 pre-composed
Pinyin syllable glyphs (PUA U+E000–U+E544) and 6,763 TrueType composite
CJK glyphs that pair each character with its Pinyin annotation.

Six variants cover the primary through sixth tonal readings of
multi-pronunciation characters (多音字). Characters with fewer
pronunciations than the variant number render without annotation.

Designer:   Catus Felis (catusf.github.io)
Repository: https://github.com/catusf/nanguo-pinyin
Base font:  Noto Sans SC (Google LLC, OFL 1.1)

Coverage
--------
- 6,763 GB2312 Simplified Chinese characters (all annotated with Pinyin)
- 20,976 CJK Unified Ideographs (U+4E00–U+9FFF)
- 6,582 CJK Extension-A (U+3400–U+4DBF)
- 1,349 PUA Pinyin syllable glyphs (U+E000–U+E544)
- Hiragana (96/96), Katakana (96/96), Bopomofo (43/48)
- Basic Latin (100%), Latin-1 Supplement (100%)
- Latin Extended-A/B (Pinyin diacritics: ā á ǎ à ē é ě è etc.)
- CJK Symbols & Punctuation (100%), Halfwidth/Fullwidth Forms (93%)
- Kangxi Radicals (95%), CJK Radicals Supplement (90%)

Technical Notes
---------------
- Format: TrueType (.ttf), UPM 1000
- Ruby glyphs are TrueType composite glyphs:
    CJK_char = [base_outline at (0,0)] + [PUA_pinyin at (0,0)]
- PUA syllables placed at ruby_y=1026, ruby_EM=320 above baseline
- usWinAscent=1400 to accommodate ruby zone above CJK body
- USE_TYPO_METRICS=OFF; sTypoAscender=880 for normal line spacing
- Letter spacing uses full advance widths (natural sidebearings)
- All 10,305 composite component flags: ARGS_ARE_XY_VALUES|ROUND_XY_TO_GRID

ChangeLog
---------
2026-05-20  v1.002  Frequency-based readings + ruby overlap fix
  - Re-ordered primary readings for 15 high-frequency heteronyms using
    Unicode kHanyuPinlu data (sources/data/kHanyuPinlu.txt, 3,799 entries):
      · 个 → ge (neutral, measure word — new slot-0 entry)
      · 了 le, 予 yǔ, 什 shén, 剎 shā, 咖 kā, 朴 pǔ, 桔 jú,
        槛 kǎn, 氓 máng, 率 lǜ, 纤 xiān, 菌 jūn, 还 hái, 钥 yào
  - Fixed neighbor-pinyin overlap on long syllables (zhuāng, chuáng,
    shuāng, …): config.yaml max_overflow_factor lowered from 1.00 to
    0.96, so wide ruby is uniformly scaled to fit within the hanzi
    advance width
  - Build pipeline cleanup: pinyin_map.json removed entirely; the char
    list now comes from refdata_cjk_composites.json, and slot-0 misses
    in FZKTPY01 now fail loud instead of falling back

2026-05-17  v1.001  Primary-reading corrections (HSK 3.0 alignment)
  - Aligned primary readings (variant -1) with HSK 3.0 vocabulary
    (sources/data/hsk30.csv, 11,093 entries)
  - Build now derives the primary-reading map from heteronym_map.json
    (slot 0); the standalone pinyin_map.json has been removed
  - 47 corrections applied, documented in
    sources/data/pinyin_map_differences.json:
      · 1 missing character added (〇 → líng)
      · 4 outright map errors fixed (缺 quē, 惹 rě, 逛 guàng, 拽 zhuài)
      · 5 sentence-final particles given neutral tone
        (吧 ba, 呀 ya, 呢 ne, 哇 wa, 啦 la)
      · 38 heteronyms re-ordered so the HSK 3.0 primary reading
        occupies slot 0 (e.g. 佛 fó, 教 jiāo, 觉 jiào, 都 dōu,
        切 qiē, 剥 bāo, 曾 céng, 血 xiě, 谁 shéi)

2025-05-13  v1.000  Initial release
  - 6,763 CJK characters annotated across 6 pronunciation variants
  - Fixed baseline alignment for Pinyin letters (ty=ruby_y)
  - Fixed letter spacing: advance-width based (natural sidebearings)
  - Fixed USE_TYPO_METRICS=OFF for correct line height in all apps
  - Added Mac Roman cmap (Platform 1, Format 4)
  - Explicit ARGS_ARE_XY_VALUES on all composite components
  - 129 additional PUA glyphs for heteronym (alternate-reading) syllables
