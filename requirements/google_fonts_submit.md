## Issue — NanGuo Pinyin (Heiti + Songti)

**Font Project Git Repo URL:**

https://github.com/catusf/NanGuo-Fonts

**Super short description of the Font Family:**

Simplified Chinese fonts with Hanyu Pinyin pronunciation guides baked into
each glyph as font-native ruby text — no HTML `<ruby>` markup needed. Six
variants surface alternate readings for multi-pronunciation characters
(多音字). Comes in two families:

- **NanGuo Heiti Pinyin** — sans-serif, Regular + Bold, based on Noto Sans SC
- **NanGuo Songti Pinyin** — serif, Regular + Bold, based on Noto Serif SC
