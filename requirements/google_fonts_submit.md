## Issue 1 — NanGuo Heiti Pinyin

**Font Project Git Repo URL:**

https://github.com/catusf/NanGuo-Fonts

**Super short description of the Font Family:**

Simplified Chinese sans-serif (Heiti) with Hanyu Pinyin pronunciation
guides baked into each glyph as font-native ruby text — no HTML `<ruby>`
markup needed. Six variants surface alternate readings for multi-pronunciation
characters (多音字). Regular + Bold, based on Noto Sans SC.
